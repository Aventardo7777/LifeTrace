# 统计方法说明

本文档用通俗的语言解释 LifeTrace 在幕后使用的统计方法，以及它们能做什么、**不能**做什么。

---

## 1. 相关系数（Pearson r）

**怎么算**：对于两个变量 `x` 和 `y`，Pearson 相关系数衡量它们线性相关的方向和强度：

```
r = Σ (xᵢ - x̄)(yᵢ - ȳ) / √(Σ (xᵢ - x̄)² · Σ (yᵢ - ȳ)²)
```

`r` 的取值范围是 `-1 ~ 1`：

| r 值 | 含义 |
|------|------|
| +1 | 完全正相关 |
| 0  | 无线性相关 |
| -1 | 完全负相关 |

同时我们计算 **p 值**（双侧检验）：p < 0.05 表示在统计意义上"不太可能由随机波动产生"。样本量 `n` 也会一起显示。

**重要提醒**：相关不代表因果。睡眠和心情正相关，并不等于"睡得多导致心情好"——两者可能同时受第三个因素（如压力）影响。

---

## 2. 移动平均

**怎么算**：对时间序列 `x₁, x₂, …, xₙ`，7 日移动平均在第 `t` 天为：

```
MAₜ = (xₜ₋₆ + … + xₜ) / 7
```

它把逐日的随机波动"抹平"，突出中长期趋势。图表中的虚线即移动平均线。

## 3. 异常检测

我们结合两种信号：

1. **Isolation Forest**：把每个日期在标准化后的多维特征空间中"孤立"起来。越容易被孤立（需要越少的分裂）的点越异常。该方法无需假设数据分布，适合多维行为数据。
2. **单指标统计偏差**：对每个指标，计算当天值相对"过去 30 天基线均值"的 z 分数：

   ```
   z = (x - μ) / σ
   ```

   当 |z| ≥ 2.5（即偏离超过约 2.5 个标准差）时标记为异常。

最终，我们为每个异常日挑出"最能解释其异常"的那个指标，并给出证据式说明，例如：

> 你的 08 月 20 日的「学习」为 1.2 小时，比过去 30 天平均水平（6.5 小时）低 81.5%。

---

## 4. 生活模式聚类（K-Means）

**怎么算**：在「睡眠、学习、运动、社交、娱乐、心情」六个维度上对日期做 K-Means 聚类。K 的取值由**轮廓系数（silhouette score）**在 2~6 之间自动挑选最优值，而不是写死。

**类别命名是数据驱动的**：对每个簇，计算其在各维度上的标准化均值（z 分数），再根据真正"突出"的特征组合生成名称——例如学习显著偏高 → "高效专注日"，心情与活动水平都偏低 → "低能量日"。因此名称取决于你的数据，而非预设结果。

---

## 5. 个人效率模型（线性回归）

**怎么算**：用多元线性回归，以「睡眠、学习、运动、社交、娱乐、压力、是否熬夜」为输入，预测当天「状态评分」（此处以心情评分 1–10 作为代理指标）：

```
ŷ = β₀ + β₁·x₁ + β₂·x₂ + … + βₙ·xₙ
```

模型在训练集 / 测试集上分别报告 R²（解释力）和 MAE（平均绝对误差）。系数经过标准化后用于展示"哪个变量对状态影响更大"（正系数 → 提升，负系数 → 降低）。

> **明确声明**：这是统计模型，不是心理或医学诊断。它只描述你历史数据中的统计关联。

---

## 6. 反事实模拟（"如果改变一个变量"）

**怎么算**：这不是预测因果，而是**匹配估计**。当你想把「睡眠」从 5 小时改成 7 小时时，我们：

1. 找出历史中睡眠 ≈ 5 小时的日子，计算各结果变量的均值（基线）；
2. 找出历史中睡眠 ≈ 7 小时的日子，计算各结果变量的均值（反事实）；
3. 对比两者的差异，输出"平均学习提高约 X%""平均心情提高约 X 分"。

> **明确声明**：这是基于历史相关数据的估计，不代表因果关系。相近睡眠时长的日子可能在别的方面也不一样，不能把差异简单归因于睡眠本身。

---

## 一句话总结

LifeTrace 提供的是**描述性**与**相关性**分析，帮助你看清规律、提出假设，而非下因果结论。做任何生活方式调整前，请结合自身判断。
